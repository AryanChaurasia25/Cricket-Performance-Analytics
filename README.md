# 🏏 Cricket Analytics Dashboard

A comprehensive cricket analytics project that provides detailed insights into batsman and bowler performance using statistical analysis and data visualization.

## 📊 Features

### 🏏 Batsman Statistics
- Total Runs
- Batting Average
- Strike Rate
- Highest Score
- Centuries & Half-Centuries
- Boundary Analysis (4s & 6s)
- Match-wise Performance
- Pdf Download

### 🎯 Bowler Statistics
- Total Wickets
- Bowling Average
- Economy Rate
- Strike Rate
- Best Bowling Figures
- Maiden Overs
- Match-wise Wicket Analysis

## 🚀 Technologies Used

- JavaScript
- Css
- Html
- Mathematic
- Seaborn

## 📈 Key Insights

- Player Performance Comparison
- Consistency Analysis
- Form Tracking
- Team Contribution Metrics
- Match Impact Evaluation

## 🎯 Project Goals

- Analyze cricket player performance.
- Generate meaningful insights from match data.
- Visualize batting and bowling trends.
- Support data-driven decision making in cricket.

## 📂 Dataset

Cricket match and player statistics collected from publicly available cricket datasets.
